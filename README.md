# Button Input, Console Output

A simple JavaScript DOM demo where clicking a button logs output to the browser console.

## Live Demo

https://arsidee.github.io/Button-Input-to-Console-Output/

## How to Use

1. Open the live demo
2. Open dev tools (Ctrl+Shift+I in Chrome)
3. Click on the "Console" tab
4. Click the **Duel!** button
5. Observe the console output
